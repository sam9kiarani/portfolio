
# Developer Portfolio Design

A modern, interactive developer portfolio website showcasing professional work, skills, and projects with a vibrant design system. Built with React, TypeScript, and Tailwind CSS for a responsive and performant user experience.

## 🎯 Project Functionality

This portfolio application features:

- **Navigation** - Sticky navigation bar with smooth scrolling and theme toggle
- **Hero Section** - Eye-catching landing section with call-to-action
- **About** - Professional background and introduction
- **Skills** - Showcase of technical skills and expertise
- **Projects** - Portfolio of completed projects with details and links
- **Contact** - Contact form and social media links
- **Dark/Light Theme** - Full theme switching capability with persistent preferences
- **Responsive Design** - Mobile-first approach with full responsive support

## 🛠️ Tech Stack

| Layer | Technology |
|-------|-----------|
| **Runtime** | Node.js |
| **Frontend Framework** | React 18.3.1 with TypeScript |
| **Build Tool** | Vite 6.3.5 |
| **Styling** | Tailwind CSS 4.1.12 |
| **Routing** | React Router 7.13.0 |
| **Theme Management** | next-themes 0.4.6 |
| **Component Library** | Radix UI (comprehensive unstyled components) |
| **Icons** | Lucide React + Material UI Icons |
| **UI Components** | Material UI (MUI) 7.3.5 |

## 📦 Key Libraries & Their Purpose

### UI Components & Design System
- **Radix UI** - Accessible, unstyled component primitives (accordion, dialog, dropdown, tabs, tooltip, etc.)
- **Material UI (MUI)** - Comprehensive component library with styled components and icons
- **Lucide React** - Modern icon library with extensive SVG icons

### Styling & CSS
- **Tailwind CSS** - Utility-first CSS framework for rapid styling
- **Emotion** (@emotion/react, @emotion/styled) - CSS-in-JS solution for dynamic styling
- **class-variance-authority** - Type-safe CSS class composition
- **clsx** - Conditional CSS class management
- **tailwind-merge** - Intelligent Tailwind class merging
- **tw-animate-css** - Advanced animation utilities

### Form & Input Handling
- **React Hook Form** - Performant, flexible form state management
- **Input OTP** - OTP/security code input component
- **React Day Picker** - Date selection component
- **CMDk** - Command menu and search functionality

### Data & Visualization
- **Recharts** - React charting library for data visualization
- **Date-fns** - Modern date utility library

### Interactive Features
- **Embla Carousel** - Carousel/slider component
- **React Slick** - Advanced carousel functionality
- **React DnD** - Drag-and-drop functionality with HTML5 backend
- **React Resizable Panels** - Resizable panel layouts
- **React Responsive Masonry** - Masonry grid layouts
- **Canvas Confetti** - Celebration animations and effects
- **Motion (Framer Motion)** - Advanced animations and transitions
- **Sonner** - Toast notifications
- **Vaul** - Drawer component

### Other Utilities
- **Popper.js** - Tooltip and popover positioning
- **React Popper** - React wrapper for Popper.js

## 🚀 Getting Started

### Installation

```bash
npm install
```

### Development Server

```bash
npm run dev
```

Starts the Vite development server at `http://localhost:5173`

### Build for Production

```bash
npm run build
```

Creates an optimized production build in the `dist/` directory
